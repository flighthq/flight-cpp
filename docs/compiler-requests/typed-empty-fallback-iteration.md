# Declared array context at empty-fallback iteration

The original `applyParticleImportOptions` body iterates `options.formats ?? []`. The preceding compiler loses the declared array domain before emitting the empty literal, producing `cpp-empty-array-element-type-unproven`. The active patch supplies that exact domain only for a direct synchronous `for…of` whose left side resolves to one nullable, closed array type and whose right side is the empty array literal. It does not infer an element from the loop binding, edit the Flight source, or choose an erased fallback type.

The existing coalesce emitter evaluates the left once and constructs an empty array only after its presence test fails. Iteration retains the selected original array handle and uses its existing `size()` and `element(index)` operations. Rechecking length each step preserves array appends and truncation from descriptor getters or callbacks, and retaining the handle preserves iteration when the source property is replaced. Elements retain their original owners. There is no new runtime API.

The focused compiler fixture has 23 passing cases, including optional and nullable fields, aliases, effectful sources, guarded owners, valid optional chains, lazy empty construction, and rejection controls. Thirteen excluded cases have byte-identical output or identical structured/semantic refusals against the preceding 118-patch compiler. These include ambiguous array/scalar unions, erased operands, open generics, other fallback expressions, nonnullable arrays, and a captured mutable loop lacking existing binding evidence. Unguarded and wrong-branch optional owners remain refused.

The emitted native fixture passes 24 checks for absent/null/empty/present arrays, original element identity and live writes, array identity, source/getter/callback evaluation and exception identity, append/truncate behavior, selected-owner lifetime, and break/continue. The fixture's TypeScript passes strict checking. Fifty-six retained callable/JSON/readonly source controls pass; one native case in that source suite is deliberately unselected and is not counted as passed. A separate ten-case optional/primitive comparison has eight passes and the same two existing failures on both compilers; that comparison establishes parity, not an all-pass suite.

The saved normal source graph emits the complete original `registerBuiltInParticleFormats.ts` module without refused declarations and without changing its IR body. Its hash and the exact function IR hash are recorded in the artifact. The existing original TypeScript public consumer still passes all 129 checks. These are source and direct emitted native controls: they do not qualify installed particle headers or all eight built-in native callback slots.

