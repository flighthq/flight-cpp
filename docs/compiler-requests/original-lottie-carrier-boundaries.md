# Original Lottie helper carrier boundaries

The original gradient and polystar modules assert one member of an imported union as its readonly row. The union stores the exact native owner, but its spelling is relative to the declaring module while the asserted row names the consumer-qualified type. Compare qualified owner names and qualify a selected cross-module `std::get` alternative. This reuses the existing checked exact-owner projection; it creates no owner or field copies.

Text alignment compares an optional literal range (`j?: 0 | 1 | 2`) twice. The second comparison excludes one literal while retaining `undefined`. Both ranges have the same optional numeric carrier. Keep that carrier unchanged instead of extracting an unjustified present payload. Strict narrowing that leaves a different absence sentinel reachable remains refused. The standalone native fixture uses the existing `value` member vocabulary for this field-independent rule; the real `j` key must come from the normal source-derived structural member table in the later coordinated package pass.

The original image layer passes a fresh object to a selected `createTexture` overload. Its literal retains the concrete `Readonly<CreateTexture2DOptions>` contextual type, while the optional-parameter summary records only `Readonly<unknown>`. For a resolved selected overload, use the fresh literal's recorded closed readonly owner at its allocation. This changes neither member evaluation nor the referenced image owner. Existing values, mutable arguments, open type parameters and incompatible expanded nominal members do not enter this path.

`compiler-original-lottie-carrier-boundaries.patch` carries these three backend fixes and three fixtures against compiler pin `806d257d2f4100de745cc97340e61c2f301b0f24`. It expires when upstream preserves these same carrier and contextual-owner facts. Qualification and the remaining original public-header boundaries are recorded in `artifacts/original-json-exact21-closure-plan.json`. Whole-module emission does not itself establish native public-header closure.

The original `toLottieShapePath` remains outside these ordinary fixes. Its source tests only that an object has `v`, then returns the original value as a readonly shape path. `{v: 7}` is in that assertion's source domain; wrapping it in an array returns the same first element. A replacement cannot require numeric arrays, fabricate a native shape-path object, eagerly copy nested arrays, or conceal errors that the original caller observes later. An escaped readonly result must retain identity and observe mutation of the original cells. The current erased `Any` to readonly-row assertion still refuses; any extension must establish those semantics explicitly.
