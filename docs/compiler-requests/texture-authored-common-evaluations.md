# Preserve the original texture factory's authored evaluations

At Flight pin `a62784923f3be814463286c9fb28edfe6ab15789`, `createTexture` computes common fields before its optional dimension switch. The default/2D branch then calls `createTexture2D`, which computes them again. The first evaluation is observable even though that branch does not consume its result. Sampler and UV getters can change values, mutate later fields, or throw. The original clone conditions also read a present sampler or vector twice and clone before the next field is evaluated.

`texture-common-options-view` moved the first evaluation into non-2D branches. `texture-create-options-views` replaced the optional switch with an undefined-only guard. These transformations changed getter order, removed the first 2D evaluation, and made null options throw. `texture-exact-cube-face-clone` also introduced a second cube sources getter and replaced slice with six indexed reads, changing holes and physical list length.

The corrective `texture-authored-common-evaluations` patch restores the common prelude and optional switch, removes the replacement branch evaluations, retains the separate 2D leaf evaluation, preserves nullish option guards, and restores ordinary cube slicing. Existing declared option views remain. The earlier patches still apply in order; the correction explicitly repairs their observable behavior. Retire the combined debt when those option-view transformations preserve the original operations directly. No source-domain restriction, native owner conversion, cached getter substitution or SDK generation is involved.

`scripts/textureGetterOrderOracle.mjs` loads complete raw and patched original modules and real dependencies. Its 50 cases compare getter traces, authored writes, changing values, exception family/message, source and resource identity, nullish defaults, and cube holes/length across all existing dimension arms. It accepts `--raw`, `--patched`, `--compiler`, and `--output` paths; the raw texture module must match the exact pin.

The native readonly 2D entry point preserves the original common prelude, dimension read and forwarding of the same row into the existing leaf. Its shared row helper preserves repeated getter reads and clone timing. Legacy carrier overloads remain. `generated_texture_options_row_test.cpp` checks that boundary and existing cube value controls: 33 checks and CTest pass. Native coverage is bounded; the complete original Lottie image caller still exposes a separate nested fresh sprite-data allocation-owner mismatch. Its rejected compile remains visible in the closure plan. The texture override's existing generated `derivedFrom` is unchanged.
