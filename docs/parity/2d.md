# 2D upstream test parity inventory

This inventory is pinned to Flight revision
`a62784923f3be814463286c9fb28edfe6ab15789`. The checkout was materialized from
`dependencies.lock.json`, and `npm run rehydrate:check` confirmed the exact revision before the
test sources below were read.

The 25 package headings follow the exhaustive 2D lane assignment. For compactness, every name in an
**Upstream modules** line is relative to `packages/<package>/src/` and has the suffix `.test.ts`.
The lists are exhaustive for those packages: they contain 345 package-scoped test modules at this
pin. The behavior summaries describe assertions in those modules; they do not claim that the
TypeScript suite passes in this repository, that the tests have been lowered to C++, or that a
package is ready for native use.
Existing native coverage comes from the repository's CTest registrations: package labels are the
authority for generated tests, while example smoke coverage is described as transitive. No build,
test execution, regeneration, or whole-SDK operation was used to produce this read-only inventory.

## Web-only exclusions

`scene2d-canvas` and `scene2d-dom` are browser-only at the pinned revision and are intentionally
outside this native 2D lane. Their tests are not included in the 345-module total. The local
`flight_cpp.generated_canvas_texture_resolver` CTest belongs specifically to the excluded
`scene2d-canvas` adapter: it checks entity markers, an initially empty resolver registry, owned
surfaces, delivery of the same `Texture2D` owner and host-image identity, resolver misses, and
destruction cleanup. That test is useful web-adapter evidence, not native applicability evidence for
any package above.

No other environment-agnostic package is added to this inventory: the lane assignment is exhaustive,
and packages owned by CORE, GL, 3D, TEXT, ANIM, or PLAT remain in their respective inventories.
